# Labs | Enterprise-1

**Languages:** [Português](README.md) | [English](README.en.md)

Each lab is a reproducible study of part of the corporate network. Real results are added only after configuration, verification and troubleshooting are actually performed.

| ID | Lab | Focus | Status |
| --- | --- | --- | --- |
| M1 | [Gold LAN segmentation](M1-GOLD-LAN/README.en.md) | VLAN, 802.1Q, SVI, example ACL, positive/negative tests | Guide and templates only; not executed |
| M2 | Gold and Data Center routing | OSPF, return paths, redistribution under review | Planned |
| M3 | WAN connectivity and security | IPsec VPN, failover and NAT | Planned |
| M4 | Silver and Bronze branches | Simplified design and static routes | Planned |
| M5 | Security and operations | Syslog, NGFW policies and troubleshooting | Planned |

**Standard:** scenario, objectives, actual environment, diagram, addressing, configuration files, `show` commands, expected/observed results, sanitized screenshots or PCAP, root cause when relevant, limitations and next steps.
